### ⚙️ How I build

> **Contracts before pipelines.** Schema validation and quality gates run before data ever reaches a mart — bad data should fail loudly, upstream.

> **Idempotent and replayable.** Backfills should be boring. Every pipeline I ship can be re-run without side effects.

> **Observability is a feature.** Metrics, centralized logs, and alerts ship with the pipeline, not after the first 2 AM page.

> **Cost is a design constraint.** Partitioning, file formats, and incremental models aren't optimizations — they're part of the initial design.
